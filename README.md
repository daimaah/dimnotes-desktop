# Dimnotes desktop releases

Release artifacts for the Dimnotes desktop shell (Windows). The source lives in
a private repository; this repository only hosts installers and the updater
manifest.

- Latest installer: https://github.com/daimaah/dimnotes-desktop/releases/latest
- Updater manifest: https://github.com/daimaah/dimnotes-desktop/releases/download/desktop-latest/latest.json

The installer is currently unsigned; Windows SmartScreen will warn on first run.
Updates are signed with the Tauri minisign key committed in the source.
